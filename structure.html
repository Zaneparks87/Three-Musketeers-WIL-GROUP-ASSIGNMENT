IT Department Staff Structure

Clear reporting lines, organizational roles, and immediate branch escalation paths across all South African metros.

Organizational Structure & Escalation Chart

To avoid communication breakdowns and ensure structured regional support layers, the corporate fleet follows the explicit matrix below:

Role / Position Reports To Core Operational Responsibilities
IT Manager Operations Officer or Executive Management
  • Approves significant technology purchases and the IT budget.
  • Approves significant changes to the IT infrastructure.
  • Analyses the needs for business continuity and the main IT risks.
Network and System Administrator IT Manager
  • Maintains firewall servers, switches, routers, and network configurations.
  • Keeps an eye on network configurations, DHCP relay, and IPsec VPN from site to site.
  • Resolves issues with connectivity and documents configuration updates.
Service Desk / IT Support Technician IT Manager
  • Accepts and records requests for IT assistance.
  • Performs preliminary troubleshooting for issues with hardware, software, and user access.
  • Notifies the appropriate administrator of complicated situations.
Database and Applications Administrator IT Manager / Software Developer
  • Performs all authorized maintenance and keeps the central database accessible.
  • Helps with integrity tests, database restoration, and backups.
  • Examines issues related to applications and data-related problems.
Information Security and Backup Coordinator IT Infrastructure Management / Security Leadership
  • Oversees security awareness and access evaluations.
  • Sets up restoration tests and keeps an eye on backup records.
  • Helps with testing and planning for disaster recovery.
