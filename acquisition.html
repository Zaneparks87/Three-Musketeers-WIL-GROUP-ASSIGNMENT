Acquisition Procedures & Approvals

This standard operating policy establishes a strict purchasing and configuration process to maintain complete hardware consistency and budget control as African Foods Company (Ltd) grows its operational reach across many regional offices.

The IT Asset process Workflow

All software additions, terminal hardware perimeter purchases and workstation deployments follow this strict process:

  • 1

    Formal Request Origin

    By specifically logging an entry into the internal IT operational portal, a branch supervisor or department manager must formally request any hardware purchases, software license additions or terminal perimeter improvements.

  • 2

    Technical Compliance Audit

    The centralized IT Manager in Cape Town must manually audit each and every request file to make sure that the target computing configurations natively support the deployment of the Windows 11 operating system environment and interface correctly with current shared network printers.

  • 3

    Vetted Supplier Restrictions

    To ensure long-term enterprise warranty coverage and technical support continuity all IT assets must come from the company's centralized register of pre-approved certified South African technology suppliers.

  • 4

    Financial Authorization Threshold Tiers

    Less than R15,000: Only require the digital approval of the IT Manager.
    Exceeding R15,000: Must go through a strict simultaneous verification by the Chief Accountant and the IT Manager in Cape Town before a legally binding purchasing order can be produced.

  • 5

    Asset Management Mapping

    Upon physical terminal delivery to any active branch site in Durban, Polokwane or Gqeberha, local support technicians must quickly tag the machine with a unique tracking number and catalogue MAC address and hardware serial code into the centralized asset database.

  • 6

    Standardized Device Staging

    The approved corporate software image which contains Windows 11, Microsoft Office 365, Sage ERP Payroll and the enterprise antivirus program must be fully flashed onto a workstation or laptop before it is delivered to an end user.

  • 7

    Certified Data Destruction

    Outdated, damaged, or malfunctioning storage devices that are being retired from the network must undergo formal data sanitization procedures using software wiping tools to completely erase all traces of confidential company and client data before being disposed of in an environmentally friendly manner.
