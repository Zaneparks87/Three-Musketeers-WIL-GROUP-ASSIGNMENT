Project Overview
African Foods Company (AFC) exports packaged South African food products to international customers. As the business expands from its baseline architecture (Cape Town and Durban) to integrate brand-new nodes in Polokwane and Gqeberha, this portal serves as a centralized, accessible framework to prevent technical drift, maintain budget compliance, and safeguard workflows.

Core Ported SOP Guidelines:
1.IT Staff Structure (structure.html):Maps out exact hierarchical reporting tiers and localized technical escalation queues.
2.Security Policy Guidelines (security.html):** Outlines multi-factor authentication (MFA) rules, network segmentation (VLANs), and POPIA data privacy alignments.
3.Acceptable Use Policy (acceptableusepolicy.html): Clearly delineates permitted and prohibited systems use for incoming enterprise end-users.
4.Acquisition Procedures & Approvals (acquisition.html):Governs strict multi-tier financial authorization gates (R15,000 threshold checks) and corporate software imaging.
5.Service Desk Protocols (service-desk.html):Establishes an automated triage engine executing strict 15-minute Critical SLA windows to avoid costly shipping backlogs.
6.Academic Reference Library (Changelog):Anchors the operational choices back to peer-reviewed IT frameworks (NIST, ISO) and South African statutory laws.

Technical Implementation Details
Frontend Languages:Semantic HTML5 and Centralized CSS3 layout architectures.
Design Standards: Completely modular external stylesheet configuration (styles.css) for high scannability and site uniformity.
Hosting Pipeline: Served dynamically as a static site via GitHub Pages cloud infrastructure.
